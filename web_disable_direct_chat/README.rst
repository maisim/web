Disable direct chat and messaging features while preserving technical
messages (log notes, automated notifications, activity tracking) in the
chatter.

**Hidden elements:**

-  "Start a meeting" button in the Discuss sidebar
-  "+" and gear buttons to add/edit channels in the sidebar
-  "New message" button in the systray messaging menu
-  "Direct Messages" section in the Discuss sidebar (conversation list)
-  "Channels" section in the Discuss sidebar (channel list)
-  "Start a conversation" button (mobile)
-  "New channel" button (mobile)
-  "To:" new message form in chat windows
-  Call and video call buttons in thread headers
-  Invite button in thread headers
-  Camera and phone buttons in chat window headers

**Preserved elements:**

-  Chatter on form views (log notes, send message, schedule activities)
-  Inbox, Starred, and History mailboxes in the sidebar
-  Systray messaging menu (notification display)
-  Message display and tracking value changes
-  Activity management and scheduling
